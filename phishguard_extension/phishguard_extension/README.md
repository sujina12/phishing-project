# PhishGuard Chrome Extension UI Prototype

Frontend-only prototype. No Flask/backend connection is required yet.

## Load in Chrome
1. Open chrome://extensions
2. Turn on Developer mode
3. Click Load unpacked
4. Select this `phishguard_extension` folder
5. Click the PhishGuard extension icon
6. Press Analyse Email

The popup uses demo phishing data so you can review the UI/UX before connecting the NLP backend.
